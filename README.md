# UNI

Web development lessons. Each lesson is a self-contained project that runs on its own —
nothing is shared between them, so you can open any folder and start there.

## Lessons

| Lesson | What it covers | Start here |
| --- | --- | --- |
| [lesson-1](lesson-1/) | A JSON API on Express, and a browser UI that talks to it | [lesson-1/README.md](lesson-1/README.md) |

## Before you start

You need [Node.js](https://nodejs.org) 18 or newer. Check what you have with:

```bash
node --version
```

Every lesson folder has its own README with the commands to run it.
